      시퀀스 데이터와 순환 신경망

      문장은 단어의 “순서”다. 앞에서 본 단어의 기억을 옆으로 넘겨 가며 읽는 신경망, 순환 신경망(RNN).

        앞 섹션의 스팸 분류기는 단어의 순서를 무시하고 “있다/없다”만 세었다. 그러면 “개가 사람을 물었다”와 “사람이 개를 물었다”가 같은 문장이 된다.

        시퀀스 데이터와 순환 신경망

        시퀀스 데이터와 순환 신경망

        Intuition — 보이지 않는 “상태”가 있다

        • 잠재 변수 (Latent Variable, Hidden Variable)
          • “관측되는 현상은 관측되지 않는 잠재 변수의 발현”
          • 잠재 변수: 기상의 상황  ·  관측 현상: 기온, 습도, 구름량, …
        • 우리는 잠재 변수를 곧바로 알 수 없음
          • 관측 값을 이용하여 잠재 변수를 추정
          • 새로운 현상이 관측되면 기존 잠재 변수를 업데이트
        • 이 숨은 상태(hidden variable)가 “지금까지 본 것”을 요약한다
        시퀀스 데이터와 순환 신경망

        순환 신경망 (RNN)의 기본 개념

        ⟨t−1⟩ 단계 상태 정보(Hidden Variable)로 ⟨t⟩ 단계 상태 정보 업데이트

        시퀀스 데이터와 순환 신경망

        RNN 모델 – 영화평 읽기

        문제 – 다음 영화평은 긍정적인가? (0 / 1 이진분류)   “This movie is a true masterpiece.”

        • 단어를 (임베딩 숫자로 바꿔) 하나씩 순서대로 넣는다
        • 각 단계의 상태(기억)는 “이전 단계의 상태 + 지금 들어온 단어”로 갱신된다 — ⟨t−1⟩ 단계 상태 정보로 ⟨t⟩ 단계 상태 정보를 업데이트
        • 그래서 마지막 상태에는 문장 전체의 정보가 순서대로 쌓여 있다
        시퀀스 데이터와 순환 신경망

        예제 (Many-to-One) – 감성 인식

        • 마지막 단계만 결과 값 출력 — 문장을 끝까지 읽은 뒤 “긍정(1) / 부정(0)”을 판단
        • 학습 방법은 1강과 같다: (영화평, 정답) 쌍을 잔뜩 주고, 예측 오차를 줄이는 방향으로 가중치를 조금씩 고친다
        여러 개(단어)가 들어가서 하나(판정)가 나온다고 해서 many-to-one. 반대로 하나가 들어가서 여러 개가 나오는 one-to-many도 가능하다 → 다음 장
        시퀀스 데이터와 순환 신경망

        예제 (One-to-Many) – 음악 작곡

        • 이전 단계 예측 값을 다음 단계 입력으로 활용 — 시작 신호 하나만 주면 음이 차례로 이어진다
        • 수많은 악보로 “다음 음”을 맞히도록 학습한 결과
        • 이 구조가 곧 뒤에서 볼 “다음 단어 예측” 언어모델의 원형
        AI Composer — 학습 반복 횟수에 따라 달라지는 작곡 베토벤 10번 교향곡 — AI가 완성한 미완성 교향곡
        시퀀스 데이터와 순환 신경망

        예제 (Many-to-Many) – 기계 번역

        • 앞부분 = 인코더: 입력 문장을 단어 순서대로 읽어, 마지막 상태에 문장 전체의 정보를 담는다
        • 중간 = 문맥 벡터(context vector): 인코더가 남긴 숫자 배열. 뒷부분에 넘겨주는 유일한 정보
        • 뒷부분 = 디코더: 문맥 벡터에서 출발해, 작곡 예제처럼 단어를 하나씩 이어 쓴다
        질문 — 어떤 문장의 정보를 모두 담으려면 변수가 몇 개여야 할까?
        실제 seq2seq 모델의 문맥 벡터는 보통 수천 개: 초기 seq2seq(Sutskever et al. 2014)는 층당 1,000개, Google NMT(2016)는 층당 1,024개를 8층으로 쌓았다. 단어 하나를 담는 임베딩(300개)보다 훨씬 크다.
        시퀀스 데이터와 순환 신경망

        기계 번역 – Google Neural Machine Translation (2016)

        • 종전 기술 – 규칙 기반 접근법
          • 문장을 여러 부분으로 쪼개고, 규칙을 적용하여 다른 언어로 옮긴 다음, 다시 조합
        • 2016년 9월 Google Neural Machine Translation (GNMT) 도입
          • 입력 문장의 각 단어를 순차적으로 순환신경망에 입력
          • 순환신경망의 은닉 계층이 단어의 순서를 반영한 정보를 기억
          • 그 정보를 이용하여 다른 언어의 문장을 생성 — 입력 문장에서 곧바로 번역문으로

          언어모델과 트랜스포머

          언어모델의 핵심 = 다음 단어 예측하기

          • 조건부 확률의 연쇄 법칙 (chain rule)
          P(“I love you”) = P(“I”) × P(“love” | “I”) × P(“you” | “I love”)
          • P(“I”) – 첫 단어가 “I”일 확률
          • P(“love” | “I”) – “I” 다음에 “love”가 올 확률
          • P(“you” | “I love”) – “I love” 다음에 “you”가 올 확률
          언어모델의 구현 — 주어진 단어 배열 다음에 등장할 단어를 예측하도록 인공신경망을 학습시키면 된다. 문장의 확률은 “다음 단어 확률”의 곱으로 얻어진다.
